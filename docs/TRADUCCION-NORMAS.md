# 翻译规范（所有语言通用）

你要把一个 Windows 截图/录屏工具 `winshotx` 的界面文本，从西班牙语（键）翻成指定语言（值）。

## 一、绝对不能翻的东西（原样保留）

### 1. 产品名
- `winshotx` —— 永远小写，永远不翻。出现在句首也一样：`winshotx` 不是 `Winshotx`。
- `Windows`、`Microsoft`、`Microsoft Store`、`GitHub`、`WebView2`、`FFmpeg`、`Impr Pant`
  （`Impr Pant` 是西班牙键盘上的 Print Screen 键名，**保留原文**，不要翻成 Print Screen）

### 2. 按键名
- `Ctrl`、`Alt`、`Shift`、`Esc`、`Win`、`Mayús`（西语 Shift）、`Tab`、`Enter`
- 组合键整体保留：`Win + Mayús + S`、`Ctrl+Mayús+S`、`Ctrl+Z`
- **不要**翻译成目标语言的按键叫法（比如日语不要写「シフト」，保留 `Shift`/`Mayús`）

### 3. 文件格式 / 技术名词
- `PNG`、`JPG`、`GIF`、`MP4`、`BMP`、`QOI`、`IBAN`、`DNI`（西班牙身份证）、`Luhn`
- 数字单位：`px`、`ms`、`fps`、`MB`、`KB`、`GB`、`%`

### 4. 占位符
- `{nombre}`、`{n}`、`{v}`、`{pct}`、`{ancho}`、`{alto}`、`{minutos}` 等
- **必须原样保留**，包括花括号。翻译后数量必须和原文完全一致。

## 二、怎么翻才像人话

### 核心原则
**想象你在给朋友解释这个按钮是干什么的**，不是在写产品手册。

### 具体做法
1. **用目标语言的母语语序**，不要照抄西语句式
2. **界面文案要短**。中文/日文/韩文尤其要比西语短，别啰嗦
3. **动词开头**表动作（"保存" 不是 "保存的"）
4. **不要直译比喻**。西语 `"se lleva un 22% de un núcleo"` 直译是"拿走一个核心的22%"，
   人话是"占用单核 22%"
5. **口语化但不轻浮**。`"No he podido copiarla"` → "复制失败" / "Couldn't copy it"
6. **技术说明要准确**，别为了顺口把意思翻错

### 长度参考
| 类型 | 目标 |
|---|---|
| 按钮/标签 | 2-6 个词 |
| 一行说明 | 不超过原文长度 1.3 倍 |
| 长段落 | 意思到位即可，可重组句子 |

## 三、逐条质量要求

1. **每条都要读一遍**：翻完回读，问自己"这话人会说吗？"
2. **不要出现原文语言**（除上面列的保护词）
3. **不要留空**、不要写 `TODO`、不要照抄英文原文
4. **标点用目标语言习惯**：中文用 `，。：`，日文用 `、。`，欧洲语言用 `,.`
5. **引号**：中文用 `「」` 或 `""`，日文用 `「」`

## 四、输出格式

返回一个 JSON 对象，键是西班牙语原文（**一个字符都不能改**），值是译文：

```json
{
  "Versión": "版本",
  "Capturar": "截图"
}
```

**只输出 JSON**，不要 markdown 代码块包裹，不要解释。

## 五、自检清单（交之前必须过）

- [ ] 条目数 = 原文条目数（383 条）
- [ ] 每个 `{xxx}` 占位符都在译文里，数量一致
- [ ] `winshotx` 全部小写且未被翻译
- [ ] 没有任何值是英文原文照抄（除非该条本来就只有品牌名）
- [ ] 随机抽 10 条，读起来像人话
